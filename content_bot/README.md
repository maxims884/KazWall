# Бот контента

Каждый день добавляет в приложение **1 новые обои** и **1–2 открытки**
(две — в четверг, к пятнице, и за 10 дней до праздника). Запускается бесплатно
на GitHub Actions в 09:00 по Астане.

Бот один, стран две: всё, что относится к стране (запросы к Commons, поздравления, праздники,
строгость отбора), лежит в `countries/kaz.py` и `countries/uzb.py`. Страна выбирается ключом
`--country uzb` или переменной `COUNTRY`; без них — Казахстан. У Узбекистана свой запуск
на GitHub Actions (`.github/workflows/content-uzb.yml`), своя ветка `content-uzb` и папка `content_uzb`.

## Где лежит контент

Сервера и Firebase нет. Картинки и их список лежат в ветке `content` этого же репозитория:

```
catalog.json            список всех картинок — его читает приложение
state.json              что бот уже использовал, чтобы не повторяться
images/nature/….jpg     картинка и её миниатюра (…s.jpg) для сетки
images/cards/…
```

Бот кладёт новые файлы в папку, GitHub Actions делает commit и push, и через несколько минут
картинки видны в приложении (оно сверяет `catalog.json` раз в 6 часов и когда список тянут вниз).
Секреты и ключи не нужны. Репозиторий должен быть **публичным**: приложение скачивает файлы
по адресам `raw.githubusercontent.com/…/content/…`, запасной адрес — CDN jsDelivr.

## Откуда берутся картинки

- **Обои** — фото Казахстана с [Wikimedia Commons](https://commons.wikimedia.org):
  сначала отобранные сообществом «качественные изображения», потом остальные крупные снимки.
  Лицензии свободные (CC BY / CC BY-SA / CC0), но автора указывать обязательно —
  приложение показывает его под картинкой, нажатие открывает страницу фото.
  Фото с узнаваемыми людьми пропускаются: для коммерческого приложения нужно их согласие.
- **Открытки** бот рисует сам: фото с [Openverse](https://openverse.org) только с лицензией
  CC0 / public domain (никаких условий) + поздравление на казахском или русском.
  Тексты и поводы — в `countries/<страна>.py`, оформление — в `cards.py`.

Pinterest и другие сайты, где картинки принадлежат авторам, не используются: за это
Google Play удаляет приложения по жалобам правообладателей.

## Настройка (один раз)

1. Создать на GitHub публичный репозиторий и отправить в него обе ветки: `main` и `content`
   (см. README в корне).
2. Settings → Actions → General → Workflow permissions: **Read and write permissions**.
3. Дальше всё идёт само каждый день. Запустить вручную: Actions → Daily content → Run workflow.

## Запуск на компьютере

Ветка `content` подключена в папку `content` рядом с ботом (`git worktree`), бот пишет прямо в неё.

```
cd content_bot
pip install -r requirements.txt
python bot.py daily --dry-run                     # контент не трогает, кладёт картинки в out/
python bot.py wallpapers --count 5 --type arch    # добавить обои в одну категорию
python bot.py cards nauryz birthday               # открытки к выбранным поводам
python bot.py remove 133219213                    # убрать неудачную картинку (по id или номеру с Commons)
python contact_sheet.py ../content out            # листы с миниатюрами, чтобы просмотреть всё разом
python bot.py daily --country uzb                 # всё то же для Узбекистана, контент — в ../content_uzb
```

После этого — commit и push в папке `content`:

```
cd ../content
git add -A && git commit -m "Контент" && git push
```

## Как это устроено

- Категории обоев пополняются по очереди (`ROTATION` в `bot.py`), запросы к Commons — в `countries/<страна>.py`.
- Отбор автоматический: по словам в названии и категориях фото (`REQUIRE_WORDS`, `JUNK_WORDS`).
  Он отсекает карты, заборы, транспорт и людей, но вкуса у него нет — изредка проходит
  скучный кадр. Его можно убрать командой `remove`: второй раз бот это фото не возьмёт.
- У Узбекистана отбор нестрогий (`STRICT = False`): отсекаются только 18+, не-фотографии (карты,
  значки, сканы), машины и снимки из соседних стран. Люди, базары, еда, детали зданий проходят,
  поэтому случайных кадров больше — просматривать листы с миниатюрами стоит чаще.
- Из одной серии почти одинаковых кадров берётся не больше двух.
- У открытки в каталоге записано, где на ней поздравление (`textAt`), — редактор в приложении
  ставит имя получателя на свободную половину.
- Одна картинка весит около 0,5 МБ, за год набирается примерно 300–400 МБ. GitHub советует
  держать репозиторий в пределах 1 ГБ — через пару лет контент стоит перенести в отдельный
  репозиторий (адреса — в `lib/config.dart`) или почистить старое.

## Что проверять раз в год

Даты Ораза айта и Курбан айта в `countries/kaz.py` и хайитов в `countries/uzb.py`
(и в приложении, `lib/services/holidays.dart`): их объявляет муфтият, могут сдвинуться на день.
